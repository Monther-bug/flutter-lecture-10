The idea

Themes and dark mode

themeThe app's style rules in one place: colors, text styles, shapes.

Widgets read the theme. Change one line in the theme, and the whole app changes.

dark modeDark backgrounds with light text.
Why? Easier on the eyes at night, saves battery on OLED screens, and many people turn it on for the whole phone.

ThemeMode

ThemeMode: who decides?

themeModeWhat you get
ThemeMode.systemFollows the phone's setting (the default)
ThemeMode.lightAlways the light theme
ThemeMode.darkAlways the dark theme
Forgot darkTheme? Flutter then uses theme even in dark mode.
Try it: Android emulator → Settings → Display → Dark theme (or the Dark theme tile in Quick Settings). iOS Simulator → Features → Toggle Appearance (⇧⌘A).

Organize

One home for the theme: lib/theme/app_theme.dart

lib/theme/app_theme.dart
// The one color we choose. Flutter makes all the others from it.
const Color seedColor = Colors.teal;

ThemeData buildTheme(Brightness brightness) {
  final colorScheme = ColorScheme.fromSeed(
    seedColor: seedColor,
    brightness: brightness,
  );

  return ThemeData(
    colorScheme: colorScheme,
    // … button and text field styles: next slide …
  );
}
lib/
├─ main.dartMyApp
└─ theme/
└─ app_theme.dartnew
One function builds both themes. Only brightness is different: no copy-paste, the Lecture 8 idea.
In main.dart: import 'theme/app_theme.dart';, then theme: buildTheme(Brightness.light) and darkTheme: buildTheme(Brightness.dark).

The switch · 1 of 3

MyApp remembers the mode

lib/main.dartMyApp is now a StatefulWidget
class _MyAppState extends State<MyApp> {
  ThemeMode themeMode = ThemeMode.system;

  void changeTheme(bool isDark) {
    setState(() {
      themeMode = isDark ? ThemeMode.dark : ThemeMode.light;
    });
  }

  // in build():
    return MaterialApp(
      theme: buildTheme(Brightness.light),
      darkTheme: buildTheme(Brightness.dark),
      themeMode: themeMode,
      home: LoginPage(onThemeChanged: changeTheme),
changeTheme(true)→ dark
changeTheme(false)→ light
setState() MaterialApprebuilds every pagegets the new colors
The choice lives only in memory: it resets when the app restarts.
Convert MyApp: click its name, Ctrl + . → Convert to StatefulWidget.

The switch · 2 of 3

ThemeButton: a moon / sun button

lib/widgets/theme_button.dart
class ThemeButton extends StatelessWidget {
  const ThemeButton({super.key, required this.onThemeChanged});

  final ValueChanged<bool> onThemeChanged;
  @override
  Widget build(BuildContext context) {
    final isDark = Theme.of(context).brightness == Brightness.dark;

    return IconButton(
      tooltip: isDark ? 'Light mode' : 'Dark mode',
      icon: Icon(isDark ? Icons.light_mode : Icons.dark_mode),
      onPressed: () {
        onThemeChanged(!isDark);
      },
    );
Theme.of(context).brightnessAre we showing dark right now? (Works in system mode too.)
onThemeChanged(!isDark)Ask for the opposite.
Light now
'Dark mode'
Dark now
'Light mode'
Prefer a switch? Switch(value: isDark, onChanged: onThemeChanged) takes the same function.

Good habits

Best practices

One file

All theme code lives in lib/theme/app_theme.dart.

Never hard-code colors

In pages, use colorScheme roles (primary, surface, onSurface…).

Contrast

Put each background with its "on" color (primaryContainer + onPrimaryContainer).

Test both modes

Check every screen in light and dark before you call it done.

Text sizes

Come from textTheme, not random fontSize numbers.

Quick check

color: Colors.black color: colorScheme.onSurface

The Lecture 9 like button used Colors.red and Colors.grey. Ask the class how they would theme it (for example colorScheme.error and colorScheme.outline).

Wrap-up

Summary + Questions

Remember

  • A theme keeps colors and styles in one place; widgets read it.
  • ColorScheme.fromSeed + brightness → a light and a dark palette from one color.
  • MaterialApp: theme, darkTheme, themeMode (system, light, dark).
  • Inside widgets: Theme.of(context).colorScheme and .textTheme, with no hard-coded colors.
  • The switch lives in MyApp's State, and it resets when the app restarts.
